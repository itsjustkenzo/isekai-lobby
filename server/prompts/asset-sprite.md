# MASTER AI PROMPT — PIXEL ART PROP FOR A 2D RPG WORLD

Create ONE object as a 2D pixel-art game sprite, using **Image 1 as the absolute style reference**. Image 1 is a sheet of existing objects from the game (trees, a bush, a rock, a stump, flowers). The new object must look as though the same artist drew it for the same game.

## 1. Style (follow Image 1 exactly)

- Authentic retro RPG pixel art with the same chunky pixel size as Image 1, crisp square pixels, no anti-aliasing.
- A dark 1-pixel outline around the whole object, like every object in Image 1.
- Simple shading in flat colour clusters, light coming from the top-left, with darker undersides, like Image 1.
- A soft, natural colour palette that sits comfortably next to Image 1's greens, browns and greys.
- No smooth gradients, no blur, no 3D rendering, no painterly or vector styles.

## 2. Viewpoint and Composition

- The same top-down RPG viewpoint as Image 1: seen from the front and slightly above, standing upright on the ground.
- Exactly ONE object, centred, filling most of the canvas, with its base along the bottom.
- Draw only the object itself. Do NOT copy the trees, rocks or other objects from Image 1 into the result.

## 3. Transparent Background — MANDATORY

- PNG with a genuinely transparent background (alpha = 0) everywhere outside the object.
- No ground, grass, floor, cast shadow, sky, scenery, border, frame, text or watermark.
- Do not draw a checkerboard pattern to fake transparency.

## 4. Strictly Forbidden

People, characters, animals (unless the object itself is a statue or decoration of one), multiple separate objects, ground tiles, shadows on the ground, perspective or isometric angles different from Image 1, text, logos, watermarks, borders, backgrounds of any colour.

**FINAL CHECK:** one object, same pixel-art style, outline and viewpoint as Image 1, transparent background.
